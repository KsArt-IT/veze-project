# Додаток для безпілотного таксі «Везе. Сама.»

> Сама везе — куди скажеш, довезе.

![License](https://img.shields.io/badge/License-MIT-green.svg)

Вебзастосунок для замовлення безпілотного таксі. Водія немає: пасажир замовляє поїздку, система
призначає вільне автономне авто, воно саме приїжджає, відчиняється за PIN-кодом і везе за маршрутом.

На першому етапі це гра: реальних авто немає, їх емулює сервер. Усе інше (пасажир, оператор,
адмін, оплата, БД, API) робиться як для реальної експлуатації, щоб згодом замінити ігрові авто
на справжні без переписування застосунку.

## Можливості

Проєкт на стадії розробки. Заплановано для MVP:

- **Пасажир** — замовлення поїздки на мапі, розрахунок вартості, відстеження авто в реальному
  часі, посадка за PIN-кодом, оплата і промокоди, оцінка поїздки, історія, кнопка «Потрібна допомога».
- **Оператор** — мапа автопарку, стрічка інцидентів, дистанційне керування (зупинити, відправити на базу).
- **Адмін** — авто, тарифи, промокоди, звіти.
- **Емулятор авто** — рухає ігрові авто маршрутом, змінює заряд, генерує інциденти.

## Технології

| Шар | Технологія |
|---|---|
| Веб | React, Next.js |
| Сервер | Node.js, Express |
| База даних | MySQL 9.7 LTS |
| Інфраструктура | Docker Compose, Adminer |

## Архітектура

Застосунок спілкується з авто лише через інтерфейс `VehicleGateway`. Зараз його реалізує
емулятор, згодом — адаптер реального автопарку. Ядро (замовлення, призначення, ціна, статуси,
оплата) не знає, емульоване авто чи справжнє.

## Швидкий старт

Потрібні Docker і Docker Compose.

```bash
git clone https://github.com/KsArT-IT/veze-project.git
cd veze-project/veze-node-app
cp .env.example .env          # і змініть паролі
docker compose up -d --build
curl localhost:3000/health    # {"status":"ok","db":"ok",...}
```

- API: http://localhost:3000
- Adminer (перегляд БД): http://localhost:8080

Детальніше — у [veze-node-app/README.md](veze-node-app/README.md).
